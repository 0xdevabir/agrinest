# AgriSathi — 4-minute demo script

## Prep
1. Start API + web (`npm run dev:api` and `npm run dev:web`)
2. Open app → **ডেমো: রহিম**
3. Printed leaf photos labeled blast / BLB
4. Backup screen recording of happy path

## Script

| Time | Say / show |
|------|------------|
| 0:00–0:30 | Meet **রহিম**, Rangpur, 0.8 ha — Bangla profile |
| 0:30–1:10 | Home: skip irrigation (rain seed) + heavy-rain Climate action |
| 1:10–2:10 | Crop Guardian: photo leaf → disease + Bangla steps |
| 2:10–2:40 | YieldMax: range drops; tap চিকিৎসা সম্পন্ন → partial recovery |
| 2:40–3:20 | FarmMarket: prices + wait hint + listing capped by yield |
| 3:20–4:00 | Close: one app, one season; offline model / voice / pilot next |

## Safety line
Advice from BRRI/DAE guidance; confirm chemicals with local agriculture officer.

## If live demo fails
Play backup recording and keep narrating. Seeded weather/prices are intentional fallbacks.
